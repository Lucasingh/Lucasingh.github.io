## 本次更新

- 全新版本管理子系统：支持绑定多个游戏文件夹，切换时自动扫描并保留各自的筛选与收藏状态
- 启动页重做为卡片式布局：版本卡片显示加载器、类型、收藏星标、隔离状态与体积，支持右键启动/收藏/隔离/打开目录/删除
- 版本自动分类：收藏 > 模组 > 原版类 > 其他，同类按版本号语义化排序
- 加载器自动识别：Forge / Fabric / NeoForge / Quilt / OptiFine / LiteLoader，并解析完整继承链
- 版本隔离：全局开关 + 单版本覆盖，隔离后使用独立的 mods / config / saves / resourcepacks 目录
- 版本健康检测：缺失 JSON、缺失 jar、缺失依赖库、缺失资源分别标记，异常不再导致崩溃
- 收藏状态、隔离设置与文件夹配置持久化到本地，重启后保留
- 新增「添加游戏文件夹」入口，默认 .minecraft 无效时可选择其它游戏目录
