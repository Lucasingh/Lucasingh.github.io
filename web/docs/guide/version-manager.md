# 版本管理

在主界面左侧导航点击「下载」进入下载页。页面分为两栏：左侧下载新版本，右侧管理已安装版本。

## 下载新版本

1. 在左侧搜索框输入版本号，例如 `1.20.1`，可用「全部 / 正式版 / 快照」切换范围。
2. 点击版本右侧的「下载」按钮。
3. 列表项内实时显示进度条、百分比与已完成文件数，底部状态栏同时显示实时下载速度。

下载流程与启动时一致：客户端、依赖库、资源文件、日志配置都会补齐，并逐个做 SHA1 校验；
已存在的文件会自动跳过，因此对已安装版本点击「下载」相当于修复缺失文件。
大文件会自动走分片多连接下载，服务器不支持 Range 时回退单连接。

离开下载页或关闭窗口会取消正在进行的下载，已写入的临时文件会被清理。

## 重命名版本

1. 在右侧「已安装版本」里找到目标版本。
2. 修改版本名输入框（默认就是当前版本名）。
3. 点击「重命名」。

重命名会同步完成三件事：

- 版本目录 `versions/<旧名>` 改为 `versions/<新名>`
- 版本 json 与客户端 jar 文件名同步修改
- json 内部的 `id` 字段改写为新名字

以下情况会被拦截并提示：名称为空、包含 `\ / : * ? " < > |` 等非法字符、与已有版本重名。
如果改名中途失败，启动器会尽量把目录回滚为原名。

## 删除版本

点击右侧「删除」，在确认框中确认后会删除整个 `versions/<版本名>` 目录。

::: warning 注意
删除只影响该版本目录，不会删除 `assets`、`libraries` 或存档。
如果该版本正在运行，文件被占用会导致删除失败，请先退出游戏。
:::

## 打开版本目录

点击「目录」会调用系统文件管理器打开 `versions/<版本名>`，方便查看 json、jar 与 natives。
