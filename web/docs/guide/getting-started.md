# 快速开始

## 系统要求

- Windows 10 及以上（当前发布的安装包为 Windows x64 自包含版本，无需另装 .NET）
- 至少 2 GB 可用内存，建议为游戏预留 4 GB

## 获取启动器

到[下载页](/download)下载并运行最新 Windows 安装包。安装包已内置运行时，无需另装 .NET；默认仅安装到当前用户目录，可按向导选择安装位置并创建桌面快捷方式。

启动器源码不对外分发；仓库仅托管文档站与构建产物。

## 首次启动

1. 在「启动设置」里填写离线用户名。
2. 确认「游戏目录」，默认是 `%APPDATA%\AovoCL\minecraft`，也可以点「浏览」指定任意目录。
3. 在左侧版本列表选择目标版本，例如 `1.20.1`。
4. 点击「启动游戏」。首次启动会自动完成以下工作：
   - 下载客户端主文件、依赖库与资源文件（约 700 MB）
   - 校验所有文件的 SHA1
   - 探测 Java；没有可用 Java 时自动下载对应版本的 JRE
   - 生成启动参数并拉起游戏进程

启动过程的日志会实时输出到右下角的「运行日志」面板。

## 下载调优

在设置页「下载性能」卡片里可以调整下载行为：

- **并发连接数**：4–32，默认 16。该数值是单文件下载与单文件内部分片共享的连接总预算，调低可减轻小带宽或镜像限速时的压力。
- **大文件分片下载**：默认开启。≥ 4 MB 的文件会先探测服务器是否支持 Range，支持时按分块多连接下载，不支持则自动回退单连接，不会报错。

下载过程中底部状态栏会显示实时速度（最近约 2 秒的滑动平均），下载页列表项内显示百分比与已完成文件数。

## 目录布局

游戏目录与官方启动器、PCL2 保持一致，便于互相导入：

```text
<游戏目录>
├─ versions/<版本名>/      # 版本 json、客户端 jar、natives
├─ libraries/              # 依赖库
├─ assets/                 # 资源文件与索引
├─ runtime/                # 启动器自动下载的 JRE
└─ cache/                  # 版本清单等缓存
```
