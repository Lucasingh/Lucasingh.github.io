# 常见问题

## 点了启动没有反应

先看「运行日志」面板最后几行：

- 停在「下载文件」：检查网络，或尝试关闭 / 打开 BMCLAPI 镜像开关。
- 停在「准备 Java 环境」：查看是否提示 JRE 下载失败，可手动指定 Java 路径。
- 提示 `无法执行指定 Java`：确认填写的路径指向 `java.exe`（Windows）或 `java`（Linux / macOS）。

## 提示 Java 版本不匹配

不同游戏版本要求的 Java 不同：

| 游戏版本 | 建议 Java |
| --- | --- |
| 1.12 及更早 | Java 8 |
| 1.17 ~ 1.20.4 | Java 17 |
| 1.20.5 及以后 | Java 21 |

不填写 Java 路径时，启动器会自动选择或下载匹配的版本；手动填写时只会给出警告，不会阻止启动。

## 下载速度很慢

- 保持「使用 BMCLAPI 镜像加速下载」开启。
- 在设置页「下载性能」里调整并发连接数（4–32，默认 16）。带宽较小或镜像限速时，降到 8–12 通常更稳。
- 大文件分片默认开启，仅对 ≥ 4 MB 且服务器支持 Range 的文件生效；镜像节点不支持 Range 时会自动回退单连接。
- 镜像失败时启动器会自动回退官方源；同一文件在不同 CDN 节点上的速度可能相差数十倍，重试往往比加并发更有效。
- JRE 下载优先使用清华 TUNA 镜像，失败后回退 Adoptium 官方。

## 离线登录出现验证失败提示

离线模式下游戏日志出现 `Failed to verify authentication`、Realms 401 属于正常现象，
不影响单人游戏与局域网联机。接入微软正版登录后该提示会消失。

## 游戏目录在哪里

默认 `%APPDATA%\AovoCL\minecraft`。在界面「游戏目录」一栏可以直接看到当前路径，
点「浏览」可以切换到任意目录（包括已有的官方启动器或 PCL2 目录）。

## 换电脑后怎么迁移

直接复制整个游戏目录即可。`versions`、`libraries`、`assets` 都是相对路径引用，
换机器后重新指定一次游戏目录就能继续使用；Java 可以重新自动检测或下载。
