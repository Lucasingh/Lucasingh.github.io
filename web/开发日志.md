# AovoCL 文档站 开发日志

> 目标：为 AovoCL 启动器搭一个纯静态文档站，内容用 Markdown 编写，构建时额外产出 `tools.json` 供工具程序拉取。
> 技术栈：VitePress 1.6 + Markdown/frontmatter + 原生 Node 脚本生成索引。
> 目录：`c:\AovoCL\web`（与启动器代码同仓库，互不影响）。

---

## 2026-11-14 站点初始化

### 一、关键决策

| 项目 | 决策 | 原因 |
| --- | --- | --- |
| 站点类型 | 纯文档站 | 用户选定；以指南/参考文档为主，`tools.json` 作为附属索引 |
| 生成器 | VitePress（免费开源，产物纯静态） | 用户指定；本地 `npm run dev` 即可预览 |
| 内容格式 | Markdown + YAML frontmatter | 工具程序可直接读源文件，索引从 frontmatter 生成 |
| 索引生成 | `scripts/gen-tools.mjs` + `gray-matter` | 不依赖 VitePress 内部 API，`dev` / `build` 前自动执行 |
| 部署 | GitHub Pages + Actions | 免费、自带二级域名，无需购买域名 |
| base 路径 | 通过 `DOCS_BASE` 环境变量注入 | 本地默认 `/`，Actions 里用 `/${{ github.event.repository.name }}/` |

### 二、目录结构

```
c:\AovoCL
├─ .github/workflows/deploy-docs.yml   # GitHub Pages 自动构建发布
└─ web
   ├─ package.json                     # dev / build / gen 脚本
   ├─ scripts/gen-tools.mjs            # 扫描 frontmatter 生成 tools.json
   ├─ docs
   │  ├─ .vitepress/config.mts         # 站点配置（导航/侧边栏/本地搜索）
   │  ├─ .vitepress/theme/             # 主题与品牌色（#2F6FEB）
   │  ├─ index.md                      # 首页
   │  ├─ guide/getting-started.md      # 快速开始
   │  ├─ guide/version-manager.md      # 版本管理
   │  ├─ guide/faq.md                  # 常见问题
   │  ├─ reference/tools-json.md       # 索引字段说明与拉取方式
   │  └─ public/tools.json             # 构建产物（已 gitignore）
```

### 三、已完成

1. VitePress 站点骨架：中文语言、导航、侧边栏、本地搜索、最后更新时间、深色模式。
2. 五篇文档：首页、快速开始、版本管理、常见问题、tools.json 参考。
3. `tools.json` 生成器：
   - 扫描 `docs/**/*.md`（跳过 `.vitepress`、`public`）；
   - 读取 `title / description / tags / updated / draft`，缺省回退到一级标题、文件名、文件修改时间；
   - 输出 `id / title / description / tags / url / file / updated`，`url` 已拼接 `base` 前缀；
   - 支持首页（`layout: home`）与目录页（`*/index.md`）的路径转换。
4. `npm run dev` / `npm run build` 前置生成索引，`tools.json` 随站点发布到根路径。
5. GitHub Pages 工作流：push `main` 且改动 `web/**` 时自动 `npm ci` → `npm run build` → 上传 `docs/.vitepress/dist` → 发布。

### 五、部署步骤（GitHub Pages）

1. 推送仓库到 GitHub，默认分支保持 `main`（或修改工作流里的分支名）。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
3. push 后工作流自动运行，站点地址为 `https://<用户名>.github.io/<仓库名>/`。
4. 若仓库名不是 `AovoCL`，无需改代码：`DOCS_BASE` 自动取当前仓库名。

Cloudflare Pages 备用：构建命令 `npm run build`、根目录 `web`、输出目录 `docs/.vitepress/dist`，
无需设置 `DOCS_BASE`（默认 `/`）。
